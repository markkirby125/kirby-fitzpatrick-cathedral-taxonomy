## Overview

The **kirby-fitzpatrick-cathedral-taxonomy** skill transforms cognitive writing science into deterministic rules for AI coding assistants, code reviews, and system documentation.

## Core Patterns

- **Cathedral Taxonomy**: Cathedral Taxonomy: state the exact number and identity of macro architectural categories before diving into the implementation details of any single component.
- **Practical Application**: Monorepo directory guides, microservice boundaries, and abstract syntax tree schemas.
- **Verification Gate**: Enforces clean syntax, zero filler, and deterministic causality.
